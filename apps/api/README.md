
# Venus Enterprises

Production-ready service booking, enquiry and quotation platform.

## Applications

- Customer website: Next.js
- Admin dashboard: Next.js
- Backend API: NestJS
- Database: Supabase PostgreSQL
- ORM: Prisma

## Development URLs

- Customer: http://localhost:3000
- Admin: http://localhost:3001
- API: http://localhost:4000/api/v1
- Swagger: http://localhost:4000/api/docs
- Health: http://localhost:4000/api/v1/health

## Installation

Install dependencies inside each application.

## Environment

Configure apps/api/.env before starting the backend.
Never commit credentials or secret keys.
